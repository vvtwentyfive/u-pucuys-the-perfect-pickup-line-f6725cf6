The brief asks for one perfect pickup line, at most 200 characters, that lands on the first read.

## The entry

> I ran a million simulations of this moment. In every single one, you smiled — so here I am, testing the theory.

## How the program works

`main.ts` runs on Node 22 using only the standard library, with no network access at all. It writes the pickup line to `/output/entry.txt`. Because there is no randomness and no outside input, the file it produces is identical on every run.
